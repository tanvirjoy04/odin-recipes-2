# Odin Recipes

Odin Recipes es un sitio web de recetas creado durante el curso Foundations de The Odin Project. 
Este proyecto me permitió practicar HTML5, incluyendo:

- Estructura de páginas web
- Encabezados, párrafos y listas
- Imágenes y enlaces
- Uso básico de Git y GitHub

Una vez completado, habré demostrado la capacidad de organizar un proyecto web sencillo y vincularlo con un repositorio remoto.
